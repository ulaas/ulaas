### Hi, I'm Ulaş 👋

I build fast, native desktop apps in **Rust** with [egui](https://github.com/emilk/egui): cross-platform (Windows, Linux, macOS), keyboard-friendly, no telemetry.

| | Project | What it is |
|---|---|---|
| 🚀 | **[Soyuz](https://github.com/ulaas/soyuz)** | A keyboard-first file explorer that never blocks: every copy/move/delete is a background job with pause, undo and crash-safe resume. Dual/quad panes, archives as folders, SFTP/S3/WebDAV, and a terminal UI. · [website](https://ulaas.github.io/soyuz/) |
| 🌳 | **[gitem](https://github.com/ulaas/gitem)** | A fast desktop Git client: commit graph, a repo-aware editor, its own diff and merge tools, pull requests for GitHub/GitLab/Bitbucket/Azure/Gitea. · [website](https://ulaas.github.io/gitem/) |
| 🧲 | **[Corrent](https://github.com/ulaas/corrent)** | A clean BitTorrent client on librqbit: magnets, RSS auto-download rules, Torznab search, streaming while downloading, Chromecast. · [website](https://ulaas.github.io/corrent/) |
| 🖥️ | **[Peek](https://github.com/ulaas/peek)** | A quiet remote desktop client for RDP and VNC with tabs, a command palette and session recording. · [website](https://ulaas.github.io/peek/) |
